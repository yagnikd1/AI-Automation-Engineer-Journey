## Phase Goal

Build reliable, ethical browser-automation programs for permitted websites and test environments while continuing guided revision of Python fundamentals and web-scraping concepts.

## Planned Duration

Phase 3 covers **28 study days**, from **Day 66 through Day 93**.

### Weeks 9–10: Selenium — 14 days

Planned coverage includes:

- Browser automation concepts and appropriate use cases
- Selenium installation and Selenium Manager
- WebDriver and browser lifecycle
- Navigation, page state, and browser controls
- Element location strategies
- CSS selectors and XPath
- Interactions with text fields, buttons, links, checkboxes, radio buttons, and dropdowns
- Explicit waits and expected conditions
- Dynamic content and synchronization
- Frames, tabs, windows, and alerts
- Scrolling, screenshots, downloads, and uploads
- Forms and authorized login workflows
- Error handling, logging, retries, and cleanup
- Reusable page objects and maintainable project structure
- Selenium checkpoint project

### Weeks 11–12: Playwright and Advanced Automation — 14 days

Planned coverage includes:

- Playwright installation and browser setup
- Browser, context, and page lifecycle
- Chromium, Firefox, and WebKit
- Locators and strict element targeting
- Auto-waiting, assertions, and explicit event waits
- Forms, dialogs, frames, tabs, popups, uploads, and downloads
- Browser contexts, cookies, sessions, and authorized authentication state
- Network inspection and permitted request/response handling
- Screenshots, tracing, debugging, and code generation
- Sync and async Python APIs
- Controlled concurrency and resource management
- Reusable architecture and configuration
- Selenium versus Playwright comparison
- Final Phase 3 checkpoint project

## Daily Learning Rules

Each study day will:

1. Begin with syntax-guided revision combining Python fundamentals and web-scraping topics in one practical program.
2. Teach the next browser-automation topic in the original roadmap order.
3. Cover every required subtopic without silently skipping or marking it complete.
4. Use simple English, reason-first debugging, and guided practice.
5. Follow robots.txt, terms of service, privacy, rate limits, and account authorization.
6. Produce one GitHub-ready Python file and one complete study guide when requested.
7. Record exact completed, unfinished, and pending topics before moving forward.

## Safety and Scope

Practice will use permitted public pages, local test pages, or purpose-built automation sites. CAPTCHA solving, stealth-driver techniques, anti-bot bypassing, unauthorized access, and prohibited account automation are outside the study scope.

## Completion Requirement

Phase 3 is complete only after:

- All Selenium topics and its checkpoint are completed.
- All Playwright and advanced-automation topics are completed.
- Python and web-scraping revision has continued throughout the phase.
- The final checkpoint is tested and documented.
- No required subtopic remains unverified or silently deferred.
